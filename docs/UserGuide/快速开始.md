# 5 分钟快速开始

这条路线只做最必要的设置。完成后，你会拥有第一个可激活的蓝图。

## 1. 安装并打开

1. 前往 [Simaritan 下载页](https://github.com/Azvf/Simaritan-Release/releases)。
2. 下载最新版本的 `.exe` 安装包。
3. 安装完成后打开 Simaritan。
4. 如果 Windows 请求管理员权限，请确认文件来自官方发布页后允许。
5. Alpha/Beta 版本会显示测试版本提醒；阅读说明后再继续。如果看到“应用完整性验证失败”，请停止使用并从官方发布页重新下载，不要忽略该提示。

**完成标志：**你能看到左侧的 **首页、蓝图、Tray、Mods、衣橱、地段、系统模组、任务、设置**。

## 2. 确认 Sims 4 路径

1. 打开左侧 **设置**。
2. 在 **游戏路径** 中确认 Sims 4 主文件夹。通常是：

   ```text
   C:\Users\你的用户名\Documents\Electronic Arts\The Sims 4
   ```

3. 如果自动检测不对，重新选择你真正使用的用户数据文件夹。
4. 确认里面能看到 `Mods` 和 `Tray` 文件夹。

**完成标志：**设置页不再提示 Mods 或 Tray 路径无效。

## 3. 启用并创建第一个蓝图

1. 完全退出《模拟人生 4》。
2. 回到 **首页**。
3. 按页面提示启用蓝图功能。
4. 如果系统提示无法创建链接，请开启 Windows 开发者模式，或用管理员身份重新打开 Simaritan。
5. 点击 **创建蓝图**，给它一个一眼能认出的名字，例如“日常主存档”或“拍照专用”。

**完成标志：**首页出现蓝图卡片，并显示 Tray、Bundle、Mod 文件和大小统计区域。

## 4. 第一次激活

1. 选中刚创建的蓝图。
2. 暂时保持默认加载范围。
3. 点击 **激活**。
4. 等待“激活完成”，不要在进度中关闭 Simaritan 或移动文件夹。

**完成标志：**蓝图显示 **当前**，状态为 **已同步，可运行**。

现在可以打开《模拟人生 4》。想继续添加家庭、穿搭和家具，请进入[完整关键链路](完整关键链路.md)。

## 卡住时先看这里

- **找不到 Sims 4 文件夹：**先启动一次游戏，让它创建用户数据目录，再回设置页刷新路径。
- **无法创建符号链接：**开启 Windows 开发者模式，或以管理员身份运行 Simaritan。
- **首次加载时间较长：**大型 Mods 库需要建立索引；可在 **任务** 查看进度。
- **路径里同时出现真实目录和链接：**不要手动删除，先导出调试日志并联系开发者。
