# 地段教程

地段模块用 Set 整理建造/购买内容。它适合把同一房间、建筑风格或配色的家具放在一起。

## 什么时候用

- 收纳一套卧室、厨房、店铺或户外家具。
- 按奶油风、复古、工业风等主题整理 CC。
- 让多个蓝图复用同一套家具。

## 跟着做

1. 打开 **地段**，创建一个 Bundle/Set。
2. 给它一个能描述空间或风格的名字。
3. 打开 **Mods**，选择 **建造/购买**。
4. 按家具、台面、管道、装饰、照明、电子设备等分类筛选。
5. 点击内容卡片的 **添加到 Bundle**，选择目标 Set。
6. 回到 **蓝图 → Bundle**，把这个 Set 加入蓝图。

## 完成标志

Set 中出现选定的家具/装饰，蓝图 Bundle 标签显示该地段 Set。

## 常见卡点

- **筛选结果为空：**物品详情索引可能仍在后台建立，先查看 Mods 页面状态。
- **内容分类和预想不同：**分类来自 Package 可读取的游戏目录信息，可打开详情确认。
- **删除 Set 前：**先从蓝图移除引用，否则蓝图会提示 Bundle 缺失。
