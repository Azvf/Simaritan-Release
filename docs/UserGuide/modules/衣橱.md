# 衣橱教程

衣橱用 Capsule 整理 CAS 内容。一个 Capsule 可以是一整套审美，也可以只收“最常用发型”或“儿童冬装”。

## 什么时候用

- 按风格、角色或场景整理穿搭。
- 从 Tray 家庭中选择模拟市民作为参考。
- 让同一套 CAS 内容被多个蓝图复用。

## 跟着做

1. 打开 **衣橱**，创建一个 Bundle/Capsule。
2. 使用清楚的名字，例如“法式通勤”“校园制服”“吸血鬼晚宴”。
3. 需要参考角色时点击 **从 Tray 添加模拟市民**，浏览家庭并选择成员。
4. 打开 **Mods**，筛选 CAS、发型、妆容、服装、鞋子或配饰。
5. 点击内容卡片的 **添加到 Bundle**，选择这个 Capsule。
6. 打开 **蓝图 → Bundle**，把 Capsule 加入需要的蓝图。

## 完成标志

Capsule 中能看到已整理的内容，蓝图 Bundle 标签也能看到这个 Capsule 引用。

## 常见卡点

- **找不到家庭：**确认 Tray 路径有效，并等待 Tray 查询完成。
- **没有预览或年龄信息：**部分 Package 元数据不完整，不影响你按文件和类型收纳。
- **删除 Capsule 前：**先检查哪些蓝图仍在引用；删除源 Bundle 会让蓝图出现缺失引用。
