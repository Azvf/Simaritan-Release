# 导入与暂存区教程

暂存区像新资源的试衣间：先扫描和预览，确认没问题后再提升到正式 Library。

## 什么时候用

- 导入别人分享的家庭、地段或房间。
- 处理同时包含 Tray 和关联 `.package` 的压缩包。
- 想先看内容，再决定是否长期保留。

## 跟着做

1. 把下载文件放进单独的普通文件夹；压缩包无需先全部散放到游戏目录。
2. 打开 **首页 → 导入 Tray**并选择这个文件夹。
3. 点击 **扫描文件夹**，检查 Tray Bundle、Mod 条目和大小。
4. 确认后点击 **导入到暂存区**。
5. 点击 **跳转到暂存区**，逐项查看详情。
6. 想保留的点击 **提升**；不需要的选择拒绝。
7. 提升完成后，在正式 Tray Library 中再次确认。

## 完成标志

已提升项目不再停留在暂存区，并能被加入蓝图。

## 常见卡点

- **只发现独立 Mod：**这个入口只导入 Tray 及其关联 Mod；独立脚本/Package 请解压后通过 Mods 或系统模组整理。
- **提示内容冲突：**资源会先保留在暂存区；提升时按页面结果处理，不要同时手动覆盖文件。
- **提示部分来源失败：**检查压缩包是否损坏、是否加密，以及文件是否仍在原位置。
- **想临时测试：**首页可开启 **加载暂存区**，但确认无误后仍建议完成提升。
