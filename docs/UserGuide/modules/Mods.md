# Mods 教程

Mods 页面把 `.package` 和相关内容变成可搜索的目录。你可以按“发型、上衣、灯具、床”等实际内容找东西，而不是猜文件名。

## 什么时候用

- 查某个 Package 里到底有什么。
- 按 CAS 或建造/购买类型找内容。
- 把 CAS 内容加入衣橱 Capsule。
- 把家具和装饰加入地段 Set。

## 跟着做

1. 打开 **Mods**，等待顶部准备状态结束；Package 列表可能先出现，物品详情随后补齐。
2. 用搜索框输入名称、类型或标签。
3. 选择分类：CAS、建造/购买、动画、拉杆或数据/脚本包。
4. 继续使用类型和子类型缩小范围，例如“CAS → 服装 → 上衣”。
5. 点击 **查看详情**，检查创作者、类型、文件路径和包内项目。
6. 点击 **添加到 Bundle**：CAS 内容选择衣橱 Capsule，建造/购买内容选择地段 Set。

## 完成标志

回到对应的衣橱 Capsule 或地段 Set，可以看到刚添加的内容。

## 常见卡点

- **首次筛选较慢：**第一次使用某类筛选时会建立索引，后续会更快。
- **名称不可用：**部分 CC 没有可读取的显示名称，可通过预览、类型或文件夹定位。
- **没有可用 Bundle：**先在衣橱或地段创建一个 Bundle。
- **删除 Mod：**先阅读 Tray 影响检查；覆盖过期、未知或失败时应重新扫描，不要绕过保护。
