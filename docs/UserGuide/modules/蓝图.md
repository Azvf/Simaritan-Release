# 蓝图教程

蓝图可以理解成“这一局要穿什么、住哪里、带哪些家具和 Mod”的完整清单。它只保存组合关系，不要求你复制多份原始文件。

## 什么时候用

- 为不同存档准备不同内容。
- 分开管理写实、二次元、复古、拍照等风格。
- 把家庭/地段、衣橱 Capsule 和建造 Set 组合到一起。

## 跟着做

1. 在 **首页** 创建蓝图，或在蓝图页选择已有蓝图。
2. 打开 **Tray** 标签，点击 **从 Tray 添加**，选择家庭、地段或房间。
3. 打开 **Bundle** 标签：
   - 从 **衣橱** 加入 Capsule。
   - 从 **地段** 加入建造 Set。
4. 打开 **统计**，查看内容来源、Tray 类型、空间占用和依赖包集中度。
5. 内容确认后选择一种方式：
   - 点击 **运行**：先准备并激活当前蓝图，成功后直接启动游戏。
   - 回到首页点击 **激活**：只切换内容，不自动启动游戏，适合想先检查结果时使用。

## 完成标志

- Tray 标签能看到已选家庭/地段/房间。
- Bundle 标签能看到衣橱和地段引用。
- 运行或激活完成后，首页将它标记为 **当前**；使用 **运行**时游戏会继续启动。

## 常见卡点

- **缺失 Bundle 引用：** 源 Capsule 或 Set 可能被删除；点击清理后重新选择。
- **Tray 条目显示失效：** 原始 Tray 文件已不在 Library，先到 Tray 页面确认文件状态。
- **统计暂不可用：** 先运行一次当前蓝图，让依赖和空间统计完成。
- **重命名不会改文件：** 它只改变蓝图显示名称，方便你自己识别。
