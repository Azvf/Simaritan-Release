# 设置教程

设置页管理游戏路径、启动方式、导出位置、界面、应用更新和诊断日志。大多数“内容加载不到”的问题都应该先从这里检查。

## 什么时候用

- 第一次启动，需要确认 Sims 4 用户数据和安装路径。
- Tray、Mods 或蓝图提示路径无效。
- 想从 Simaritan 启动游戏、检查更新或切换主题。
- 需要向开发者提供脱敏诊断日志。

## 跟着做

### 游戏路径

1. 在 **游戏路径** 找到 Sims 4 主文件夹。
2. 它通常位于：

   ```text
   C:\Users\你的用户名\Documents\Electronic Arts\The Sims 4
   ```

3. Simaritan 会从主文件夹派生 Mods 和 Tray 路径。
4. 修改后点击 **刷新路径快照**，确认错误提示消失。

如果你使用 OneDrive 或自定义 Documents 位置，请选择游戏当前真正读取的文件夹，不要照抄示例路径。

### 游戏启动

1. 在 **The Sims 4 安装文件夹** 中确认 EA app 或 Steam 的游戏安装位置。
2. 选择 DX11 或需要兼容旧环境时选择 DX9。
3. 保存后可点击 **打开 TS4**。

蓝图激活完成后再启动游戏；打开 TS4 不会替代蓝图激活。

### 导出文件夹

Tray 首次导出时可以选择位置，设置页会记住它。建议使用独立文件夹，例如：

```text
D:\Simaritan Exports\Tray
```

不要把导出位置直接设为当前 Mods 或 Tray Library，以免把分享副本误当成正式内容。

### 外观、更新与日志

- **界面：** 选择语言和浅色/深色主题。
- **检查更新：** 发现新版本后可下载安装，应用会重启。
- **导出调试日志：** 生成经过脱敏的 ZIP，并在文件管理器中定位。
- **清除缓存：** 只清除可重建索引，不会删除 Mods、Tray、日志和配置；清除后首次加载会变慢。
- **关于：** 查看版本，并通过 QQ 群或 Discord 反馈问题。

## 完成标志

游戏路径不再报错，Mods/Tray 能正常加载；需要启动游戏时，**打开 TS4** 能找到正确的可执行文件。

## 常见卡点

- **自动检测到旧文件夹：** OneDrive、多个 Windows 用户或迁移过 Documents 时常见，请手动选择当前游戏实际使用的位置。
- **“尚未创建用户数据文件夹”：** 先正常启动一次《模拟人生 4》并进入主菜单，再退出并刷新路径。
- **更新失败：** 保留当前安装，导出日志后从官方 Release 页下载安装包覆盖安装；仍无法解决时，到 **设置 → 关于** 通过 QQ 群或 Discord 反馈。
