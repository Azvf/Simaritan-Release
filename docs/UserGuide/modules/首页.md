# 首页教程

首页是你的总控制台：选择本次要玩的蓝图、检查会加载多少内容，然后激活。

## 什么时候用

- 第一次创建蓝图。
- 在不同存档、主题或拍照方案之间切换。
- 进游戏前确认 Tray、Bundle、Mod 数量和总大小。
- 临时决定是否加载 Bundle、系统模组或暂存区内容。

## 跟着做

1. 点击 **新建蓝图**，使用能说明用途的名字。
2. 在 **所有蓝图** 中选中一张卡片，上方会显示它的预览。
3. 检查 **加载范围**：
   - **加载 Bundle 内容：**衣橱 Capsule 和地段 Set。
   - **加载系统模组：**每个蓝图都需要的脚本/玩法 Mod。
   - **加载暂存区：**仍在审核的新资源，平时建议关闭。
4. 查看 Tray、Bundle、Mod 文件和大小统计。
5. 退出《模拟人生 4》，点击 **激活**。

## 完成标志

蓝图卡片显示 **当前**，并且状态为 **已同步，可运行**。

## 常见卡点

- **统计一直在计算：**第一次索引大型资料库需要时间，可到 **任务** 查看进度。
- **激活按钮不可用：**通常是路径、后台准备或加载范围仍在保存；先查看页面错误，再到设置刷新路径。
- **“内容未同步”：**不是文件丢失，表示这个蓝图有变化，需要重新激活。
- **不要在游戏运行时切换：**先退出游戏，避免它同时读取正在变化的 Mods/Tray。
