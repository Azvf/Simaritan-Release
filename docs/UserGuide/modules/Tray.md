# Tray 教程

Tray 保存家庭、地段和房间。Simaritan 会把同一个作品对应的多个 Tray 文件组合成一张可以预览的卡片。

## 什么时候用

- 找家庭、地段或房间。
- 查看家庭成员、类型和预览图。
- 把 Tray 项目加入蓝图。
- 导出分享内容，并带上已解析的依赖 Mod。
- 检查暂存区的新资源。

## 跟着做

1. 打开 **Tray**，确认顶部范围是正式 Library、某个蓝图或暂存区。
2. 使用类型、作者、时间、标签等筛选缩小结果。
3. 点击卡片的 **查看详情**。
4. 根据目的选择：
   - **添加到蓝图：** 让它进入某个主题方案。
   - **导出：** 保存 Tray 文件及已解析依赖到导出文件夹。
   - **优化纹理：** 创建经过优化的输出；原始项目不会因为点开详情而自动修改。
   - **提升：** 把暂存内容正式收入 Library。
5. 长任务开始后，到 **任务** 查看进度。

## 完成标志

添加后可在 **蓝图 → Tray** 看到条目；导出后可在设置中记录的导出位置找到结果。

## 常见卡点

- **没有预览图：** 部分 Tray 文件本身没有可用缩略图，不代表内容无效。
- **依赖数量仍在准备：** 等待 Tray 依赖索引完成，不要反复重启任务。
- **暂存区是空的：** 先从首页执行“导入到暂存区”。
- **修改或删除前：** 先退出游戏；看到依赖覆盖不完整或文件已变化时，不要强行继续。
