# 任务教程

任务页负责显示需要较长时间的操作，例如导入、导出、提升、贴图优化和依赖分析。

## 什么时候用

- 想确认操作是否仍在进行。
- 想查看完成、失败或取消的历史。
- 页面没有立刻更新，想知道后台是否还在处理。

## 跟着做

1. 开始一次导出、导入或优化操作。
2. 打开左侧 **任务**；数字徽标表示当前活动任务数量。
3. 在 **进行中** 查看阶段、百分比和说明。
4. 完成后到 **历史** 查看结果。
5. 确认不再需要记录时，点击 **清除已完成**。

## 完成标志

任务进入“完成”终态，相关页面随后显示新的内容或导出结果。

## 常见卡点

- **进度暂时不变：**大型 Package 的单个步骤可能耗时较长；只要阶段仍更新，不需要重复启动。
- **任务失败：**记录任务名称和错误，前往设置导出调试日志。
- **取消后仍显示：**等待取消确认完成；不要直接结束 backend 进程，否则可能只留下未确认状态。
