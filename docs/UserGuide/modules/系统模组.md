# 系统模组教程

系统模组是“无论切换到哪个蓝图都要保持启用”的功能性 Mod，常见于脚本、玩法框架或基础依赖。

## 什么时候用

- 某个脚本 Mod 是所有存档都需要的。
- 多个蓝图共同依赖同一套玩法框架。
- 不想每次切换蓝图都重新选择基础功能包。

## 跟着做

1. 先把功能性 Mod 按独立的一级文件夹整理在 Mods Library 中。
2. 打开 **系统模组**并点击重载。
3. 在 **常驻模组** 中选择要持续启用的文件夹。
4. 回到 **首页**，开启 **加载系统模组**。
5. 重新激活目标蓝图。

## 完成标志

系统模组显示 **已选**，首页预览的 Mod 数量随选择更新。

## 常见卡点

- **没有扫描到：**系统模组按 Mods 根目录下的第一级文件夹识别；散放文件不会作为独立模组组出现。
- **不要把全部 CC 设为常驻：**这里更适合脚本、玩法和公共依赖；普通发型、衣服、家具应通过 Bundle 管理。
- **修改选择后：**需要重新激活蓝图，游戏侧内容才会同步。
