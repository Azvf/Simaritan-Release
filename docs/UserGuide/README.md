# Simaritan 用户教程

欢迎来到 Simaritan。你不需要先弄懂文件结构、依赖索引或符号链接，只要先选一个目标，跟着步骤做就可以。

## 第一次使用

- [5 分钟快速开始](快速开始.md)：只完成安装、路径确认、创建蓝图和第一次激活。
- [完整关键链路](完整关键链路.md)：从下载资源、导入暂存区、整理内容，一直做到进入游戏。

## 先认识 5 个词

- **蓝图（Blueprint）：**一次游戏要加载的完整内容方案。
- **Tray：**《模拟人生 4》保存家庭、地段和房间的文件区域。
- **Bundle：**一组可以反复加入不同蓝图的内容集合。
- **Capsule：**衣橱里的 CAS Bundle，可以理解为一套穿搭主题包。
- **暂存区：**新资源的试衣间。内容先放这里检查，确认后再提升到正式资料库。

## 安全提醒

> 切换蓝图、提升资源或修改 Tray 前，请先退出《模拟人生 4》。不要在操作进行中手动移动 Mods、Tray、Library 或 `VirtualWorkspaces` 文件夹。

如果页面上的名称与教程不同，请先在 **设置 → 应用 → 检查更新** 确认版本；教程以当前发布版中文界面为准。
