# 完整关键链路：从下载资源到进入游戏

假设你刚下载了一套带家庭、地段和 CC 的分享资源，这篇教程会把它整理成一个可随时切换的蓝图。

## 开始前

- 退出《模拟人生 4》。
- 把下载的压缩包或文件集中到一个普通文件夹，不要直接塞进游戏的 Mods/Tray。
- 在 **设置** 中确认 Sims 4 用户数据路径正确。
- 已完成[第一次蓝图启用](快速开始.md)。

## 第一步：创建一个主题蓝图

1. 打开 **首页**，点击 **新建蓝图**。
2. 使用能说明用途的名字，例如“海边度假存档”或“校园拍照”。
3. 如果页面询问是否预装现有 Tray：想从干净方案开始就不包含；想保留现有家庭/地段就选择包含当前 Tray。

**完成标志：** 首页和蓝图页都能选到这个蓝图。

## 第二步：导入分享资源

1. 在 **首页 → 导入 Tray** 点击选择文件夹。
2. 选择刚才准备的分享资源文件夹。
3. 点击 **扫描文件夹**，先查看识别到的 Tray Bundle、Mod 条目和总大小。
4. 确认结果后点击 **导入到暂存区**。
5. 点击 **跳转到暂存区**。

> 这个入口只接收 Tray 及其关联 Mod。只有独立 `.package` 或 `.ts4script` 时，请解压后通过 Mods 或系统模组整理。

**完成标志：** Tray 页面顶部范围显示 **暂存区**，并出现刚导入的家庭、地段或房间。

## 第三步：在暂存区检查并提升

1. 打开每张卡片的 **查看详情**，确认标题、预览图和类型。
2. 不想保留的项目选择拒绝；确认要留下的项目点击 **提升**。
3. 如果出现同名内容冲突，按页面提示处理，不要同时在资源管理器里移动对应文件。
4. 等待任务完成。

**完成标志：** 项目从暂存区消失，并能在 Tray 的正式 Library 范围找到。

## 第四步：把 Tray 项目加入蓝图

1. 在 **Tray** 找到目标家庭、地段或房间。
2. 点击 **添加到蓝图**并选择第一步创建的蓝图。
3. 打开 **蓝图 → Tray**，确认条目已经出现。

## 第五步：整理穿搭和家具

### 穿搭内容

1. 在 **衣橱** 创建 Capsule，例如“海边度假穿搭”。
2. 在 **Mods** 使用 CAS、发型、服装、妆容等筛选找到内容。
3. 点击卡片的 **添加到 Bundle**，选择刚创建的 Capsule。
4. 回到 **蓝图 → Bundle**，加入这个衣橱 Capsule。

### 建造内容

1. 在 **地段** 创建 Set，例如“海边民宿家具”。
2. 在 **Mods** 切换到建造/购买分类，筛选家具、灯具或装饰。
3. 点击 **添加到 Bundle**，选择刚创建的建造 Set。
4. 回到 **蓝图 → Bundle**，加入这个 Set。

**完成标志：** 蓝图的 Bundle 页面能看到衣橱和地段引用。

## 第六步：选择常驻系统模组

1. 打开 **系统模组**。
2. 选择希望所有蓝图都加载的脚本或玩法 Mod。
3. 回到 **首页**，确认 **加载系统模组** 已开启。

不要把只服务于某个主题蓝图的普通 CC 全部设为系统模组，否则每个蓝图都会加载它们。

## 第七步：预览本次加载内容

1. 回到 **首页**并选中目标蓝图。
2. 检查加载范围：** 加载 Bundle 内容**、**加载系统模组**，以及仅在测试未审核资源时才开启的 **加载暂存区**。
3. 查看 Tray、Bundle、Mod 文件和总大小。

**完成标志：** 页面没有阻塞错误，统计完成或明确提示仍在后台整理。

## 第八步：激活并进入游戏

1. 确认游戏已关闭。
2. 选择一种方式：
   - 想先检查结果：在首页点击 **激活**，等待蓝图显示 **当前**且状态为 **已同步，可运行**，再从 **设置 → 打开 TS4**、EA app 或 Steam 启动游戏。
   - 想一步完成：在蓝图页点击 **运行**。Simaritan 会先准备并激活这套内容，成功后直接启动游戏。
3. 准备期间不要关闭 Simaritan，也不要手动移动 Mods、Tray、Library 或 `VirtualWorkspaces` 文件夹。

**完成标志：** 目标蓝图显示 **当前**，游戏已使用这套内容启动。

## 想换另一套内容时

1. 退出游戏。
2. 在首页选择另一个蓝图。
3. 检查加载范围并点击 **激活**。
4. 等待新蓝图显示 **当前**后再进游戏。

你不需要手动替换 Mods 或 Tray 文件夹；蓝图切换就是用来完成这件事的。
