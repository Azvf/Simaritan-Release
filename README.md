# Simaritan Releases

Official Windows releases and updater channel manifests for [Simaritan](https://github.com/Azvf/SimsToolkit).

- Download installers from [Releases](https://github.com/Azvf/Simaritan-Release/releases).
- Stable, Beta, and Alpha updater manifests are published under `channels/` by the verified release workflow.
- Source code and issue tracking remain in [Azvf/SimsToolkit](https://github.com/Azvf/SimsToolkit).
