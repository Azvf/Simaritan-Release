If your Mods folder has grown to the point where you know you downloaded something but can never find it, Simaritan is here to help. It reads the game content you actually own so you can preview, search, categorize, and combine it. Create different **Blueprints** for different saves, styles, or ways to play, then switch between them with a single click.

## Download and Install

1. Open the [Simaritan download page](https://github.com/Azvf/Simaritan-Release/releases).
2. Open the newest release at the top and select the single `.exe` installer under **Assets**.
3. Once downloaded, double-click to install. For future releases, simply install the new version over your existing installation.

## What You Can Do

- **Blueprints:** Combine households, lots, outfits, furniture, and always-on mods into a setup for your next play session.
- **Tray:** Browse households, lots, and rooms with preview images, and automatically include resolved Mod dependencies when exporting.
- **Mods:** Search by categories such as hairstyles, clothing, makeup, furniture, and lighting instead of digging through folders.
- **Wardrobe:** Organize CAS content into Capsules, such as "Autumn Barista" or "Retro Y2K Glam."
- **Lots:** Organize Build/Buy content into Sets, such as "Cream-Toned Bedroom" or "Seaside Cottage Furniture."
- **System Mods:** Keep script and gameplay mods enabled across all Blueprints.
- **Import and Staging:** Preview Tray and Mod content shared by others before deciding what to add to your library.
- **Tasks:** Run exports, imports, and optimizations in the background without waiting on the screen.

## Four Things to Know Before You Start

1. Exit The Sims 4 before switching or activating a Blueprint.
2. When activating a Blueprint for the first time, check that **Settings** shows the Sims 4 user data folder you actually use.
3. Blueprints require Windows Developer Mode or administrator privileges to create folder links. Follow the prompts if Windows asks for permission.
4. Once a Blueprint is active, do not manually move the Library or `VirtualWorkspaces` folders managed by Simaritan.

## Need Help?

- Open **Settings → Application → Export Debug Logs** to create a diagnostic ZIP with sensitive information removed.
- Then go to **Settings → About** and report the issue through the QQ group or Discord, including a description of the problem and the logs.
